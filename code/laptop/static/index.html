Buffer time and gate control

Buffer time: how long a station may stay busy before its LED turns red and it is called the bottleneck. Each station has its own buffer, because each does a different job (a longer job needs a longer buffer). Twice the buffer = suspected breakdown. The UNO saves all three in EEPROM.

Gate: opens when S1 is empty (S1 green steady), closes as soon as a box reaches S1. WIP limit "Off" = only this rule. A limit n > 0 switches on CONWIP (constant work in progress): the gate also waits until the line holds fewer than n boxes.
